# Website Institucional da KH4OS

Este é o repositório oficial do website institucional da KH4OS[cite: 1], a Camada de Confiança e Proveniência de Execução para a Economia de Agentes de IA. O site serve como nosso hub central, apresentando nossa tese principal: **Autonomia é o Próximo Estágio da Inovação**.

> **Nota sobre nosso Pivot:** A KH4OS começou originalmente como uma fábrica de Micro-SaaS (focada no produto AluguelOK)[cite: 1]. Desde então, evoluímos para uma empresa de infraestrutura Deep Tech. Este site reflete nosso novo foco em segurança criptográfica e atestação em nível de hardware para IA autônoma.

## 🚀 Nossa Tecnologia Central: Nó d10nysus
Nosso produto principal é a arquitetura **d10nysus**. É a primeira camada de atestação de execução pronta para integração, construída para provar — via criptografia de hardware (Multi-TEE) e jitter termodinâmico — que uma ação foi genuinamente executada por um agente de IA, derrotando operadores humanos, scripts determinísticos e credenciais roubadas.

## 🎯 Sobre o Projeto
O website da KH4OS foi desenvolvido para servir como o principal ponto de contato e autoridade da marca[cite: 1]. O objetivo é apresentar nossa tese de negócios: nós construímos a infraestrutura necessária para trazer confiança matemática e física à economia autônoma.

Este site detalha nossa abordagem deep tech, apresenta nosso roadmap estratégico e converte o interesse de clientes e parceiros em conversas estratégicas[cite: 1].

## ✨ Principais Funcionalidades
O site é construído no estilo "one-page", com seções bem definidas e navegação suave[cite: 1]:

*   **[x] Seção Hero:** Apresentação da tese central da KH4OS ("Autonomia é o próximo estágio da inovação")[cite: 1].
*   **[x] A Tese:** Explica o problema central (Identidade de Chave vs. Proveniência de Execução).
*   **[x] Mergulho Técnico:** Detalha a arquitetura do nó d10nysus (Multi-TEE, Jitter Termodinâmico, Zero-Allocation).
*   **[x] Roadmap Estratégico:** Delineia nossa visão em camadas (Camada 1 à Camada 3).
*   **[x] Sobre Nós ("Nossa Equipe"):** Apresentação criativa do conceito "one-person army" e das competências da fundação[cite: 1].
*   **[x] Dúvidas (FAQ):** Respostas claras sobre a KH4OS e nossa tecnologia[cite: 1].
*   **[x] Call-to-Action (CTA):** Seção de conversão com link direto para WhatsApp[cite: 1].
*   **[x] Rodapé Completo:** Mapa do site com links para páginas legais (/Policy, /Help) e informações de contato[cite: 1].

## 💻 Tecnologias Utilizadas
Este projeto é um site estático construído com tecnologias web modernas e um conjunto de bibliotecas de animação de alta performance[cite: 1]:

*   **HTML5:** Para a estrutura semântica do conteúdo[cite: 1].
*   **CSS / UI Framework:** Para design responsivo e moderno, adaptado dos nossos layouts anteriores[cite: 1].
*   **JavaScript (ES6+):** Para toda a interatividade[cite: 1], incluindo animações de scroll, carrosséis dinâmicos e lógica de UI.
